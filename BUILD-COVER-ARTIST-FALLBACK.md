# MixParty — Secours jaquette artiste

Ordre de recherche :

1. Apple/iTunes avec correspondance artiste + titre ;
2. MusicBrainz + Cover Art Archive ;
3. pochette fiable d’un autre titre du même artiste via Apple ;
4. logo MixParty côté interface si aucun résultat.

La source du secours est enregistrée sous `APPLE_ARTIST_FALLBACK`.
