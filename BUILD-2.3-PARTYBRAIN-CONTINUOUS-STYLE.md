# PartyBrain — continuité de style

Ce correctif conserve le style dominant de la soirée sur plusieurs recommandations automatiques.

- Les morceaux ajoutés par les utilisateurs pèsent davantage que les choix PartyBrain.
- Le contexte analyse les huit derniers morceaux.
- Gims est reconnu dans le contexte rap français.
- PartyBrain cherche d’abord plusieurs candidats du même style ou d’un style compatible.
- Le secours classe désormais la compatibilité de style avant la popularité globale.
- La sélection examine vingt recommandations au lieu de cinq.

Ainsi, après Gims puis un titre automatique cohérent, PartyBrain reste dans la même ambiance au lieu de revenir immédiatement vers « Nuit de folie ».
