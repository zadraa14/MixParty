Installation
============

1. Remplace apps/web/app/page.tsx par le fichier fourni.
2. Copie les fichiers du dossier apps/web/components dans ton dossier apps/web/components.
3. Vérifie que public/mixparty-logo-officiel.svg existe.
4. Lance depuis apps/web : npm run dev

Le fond utilise un canvas fixe derrière toute la page. Il ne modifie pas la hauteur du document.
Le doublon onClick/disabled du bouton a été supprimé et le JSX a été entièrement réorganisé.
