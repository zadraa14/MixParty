# MixParty V6.2 — PartyBrain Intelligence Event Engine

## Objectif

Préparer l'apprentissage comportemental des soirées sans modifier le fonctionnement visible de MixParty.

## Événements enregistrés

- `PARTY_CREATED`
- `PARTICIPANT_JOINED`
- `PARTICIPANT_LEFT`
- `SONG_ADDED`
- `SONG_VOTED`
- `SONG_PLAY_STARTED`
- `SONG_PROGRESS` (palier de 30 secondes)
- `SONG_PLAY_COMPLETED`
- `SONG_SKIPPED`

## Données et vie privée

Les acteurs ne sont pas stockés en clair. Un hash court et stable est généré pour permettre l'analyse des comportements sans conserver le nom du participant.

Chaque événement inclut le contexte léger utile à PartyBrain Intelligence : âge de la soirée, heure, nombre de participants, morceau, votes, position dans la file, source de l'ajout et progression de lecture.

## Stockage

Fichier JSON Lines persistant : `party-intelligence-events.jsonl` dans `PERSISTENT_DATA_DIR`.

Une ligne correspond à un événement. Le format est léger, append-only et facilement exportable vers une base analytique plus tard.

## API

- `GET /partybrain/intelligence/stats`
- `GET /partybrain/intelligence/events?limit=500`
- `GET /partybrain/intelligence/export`
